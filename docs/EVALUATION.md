# Agent 插件评测与实验规范

本规范用于上下文压缩、记忆、skill 演化以及 harness 策略优化。目标不是产生一个更高的单项分数，而是证明候选在明确边界内相对当前稳定基线有可复现的净收益。

## 评测层次

| 层次 | 作用 | 典型证据 |
| --- | --- | --- |
| 单元与属性测试 | 验证确定性算法和不变量 | 配对、排序、预算、版本、序列化、幂等性 |
| 组合回放 | 验证真实 DSH 插件树和日志投影 | 固定 session fixture、scripted model、snapshot |
| 任务评测 | 验证 agent 是否完成实际工作 | 文件状态、命令结果、测试结果、结构化 grader |
| 真实模型试验 | 验证非确定性端到端表现 | 多次重复、置信区间、成本与延迟 |
| 影子或灰度运行 | 验证真实分布与运行稳定性 | 无用户影响的候选比较、停止与回滚记录 |

下层未通过时不进入更昂贵的上层。keyless 回放不能证明真实模型有效，真实模型偶然成功也不能替代确定性回归测试。

## 数据集与防污染

- 将案例分为开发集、验证集和保留测试集；只有最终晋级检查访问保留集结果。
- 数据集、评分器、依赖、模型标识、采样参数和运行环境都要固定版本。
- 同一任务族保留正常、边界、长上下文、故障恢复和对抗性案例。
- 候选不得读取期望答案、评分器实现、其他候选结果或保留集标签。
- 真实用户轨迹进入 fixture 前必须获得授权并去标识化；优先构造最小复现。

## 公共指标

每次实验至少报告：

- 任务成功率与失败类型。
- token 输入、输出与节省比例。
- 端到端延迟及高分位延迟。
- 模型调用次数和估算成本。
- 无效工具调用、重试、超时和异常率。
- 安全、隐私、越权和不可逆副作用事件。
- 与基线的逐案例差异，而不只报告平均值。

不同能力增加专项指标：

| 能力 | 专项指标 |
| --- | --- |
| 上下文压缩 | 关键事实召回、约束保留、工具调用/结果配对、后续任务成功、重复压缩漂移 |
| 记忆 | 检索 precision/recall、过期记忆命中、冲突处理、更正传播、跨作用域泄漏 |
| Skill 演化 | 触发 precision/recall、任务增益、负迁移、指令长度、危险工具行为 |
| Harness 策略 | 回归数、死循环/停滞率、恢复率、工具效率、用户干预次数 |

LLM-as-judge 只能作为一个信号。使用时固定 rubric 和位置顺序，混入人工校准样本，并同时保留可执行或结构化评分器。

## 晋级规则

实验开始前写明主指标、不可退化指标、最小实际改进幅度和停止条件。默认门槛：

1. 所有确定性回归和安全测试通过。
2. 主指标达到预先声明的最小改进，而不是仅仅数值更高。
3. 不可退化指标没有超过允许范围，且不存在新的严重失败类型。
4. 非确定性案例进行足够重复，并报告分布或置信区间。
5. 最差案例经过人工审阅，实验可以由保存的 manifest 重放。
6. 生成独立候选版本和回滚说明；自动晋级还需要影响范围与熔断条件。

基线与候选没有显著差异时保持基线。不得在看到结果后修改成功标准而仍把实验称为预先验证。

## 推荐的 `evals/` 布局

```text
evals/
├── README.md               # 运行方式和数据许可
├── manifest.example.json   # 可提交的运行参数模板
├── cases/                  # 版本化输入与期望不变量
├── fixtures/               # 去标识化回放数据
├── scorers/                # 独立评分器
└── reports/                # 经过审查的小型晋级报告
```

大体积原始轨迹、模型响应、临时数据库和包含隐私的数据放入被忽略的本机实验目录，不提交仓库。报告引用数据集和候选的内容摘要，以便验证对应关系。

## 实验记录模板

```markdown
# EXP-YYYY-MM-DD-短标题

## 决策
候选 / 基线 / 未决，以及允许的部署范围。

## 假设
哪一项机制会改善哪个指标，以及为什么。

## 基线与候选
仓库 commit、配置摘要、模型与依赖版本。

## 数据与方法
数据集版本、切分、样本量、重复次数、评分器和运行环境。

## 预注册门槛
主指标、不可退化指标、最小改进、停止条件。

## 结果
逐案例差异、聚合指标、方差或置信区间、成本和延迟。

## 失败与风险
最差案例、未知项、污染检查、安全与隐私事件。

## 晋级与回滚
批准者或策略、影响范围、监控、熔断条件和回滚版本。
```

实验报告是决策证据，不是运行日志。只保留复现所需事实，不保存隐藏推理或敏感内容。
